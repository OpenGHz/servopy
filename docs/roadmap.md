# 功能状态与后续工作

本清单对应 `0.2.0`，区分包内已实现能力和仍需实现的功能。

## 本批已完成

| 功能 | 实现与验证 |
|---|---|
| 原生关节位置指令 | Python/C++ 均支持 JointPosition，具备完整关节名称映射、连续关节角差、限位、超时与制动 |
| 可复用 Python 位置 IK 接口 | PositionIKAdapter 验证输入、有效限位、可选连续性、任务位姿残差；保留源时间戳，失败返回 StopCommand |
| Panda 示例采用包级接口 | 直接关节目标与 IK 模式均使用原生 JointPosition，IK 校验不再由示例重复实现 |
| 有效限位与目标误差诊断 | Servo.limits 返回独立副本；joint_position_error 区分目标误差与参考跟踪误差 |

已有能力还包括 JointJog、Twist、Pose、内置阻尼微分 IK、奇异性减速/离开策略、外部碰撞结果接口、URDF/串联运动学、Pinocchio 后端，以及 MuJoCo viewer 与录制。验证范围见 [validation.md](validation.md)。

## 仍未完成

| 建议顺序 | 功能 | 需要补齐的实现与验收 |
|---|---|---|
| 1 | 实际几何碰撞检查 | 目前只有 CollisionSample 输入。需要可选后端计算自碰撞/环境距离，明确模型过滤、反馈时间戳和失败行为，测试靠近、接触、离开及过期结果 |
| 2 | jerk / Ruckig 轨迹平滑 | 目前限制速度与加速度。需要可选后端，联合验证加速度连续性、急停、位置边界可行性和采样周期变化，不能仅在输出追加滤波 |
| 3 | 控制周期调度与设备适配 | 当前由调用方安排周期与设备 I/O。需要驱动协议、缓冲、超时/取消/恢复约定和过载测试；Python 线程不代表硬实时 |
| 4 | 内核自定义微分 IK、QP 与冗余控制 | 外部位置 IK 已可用；直接替换 Pose/Twist 内核求解、QP 约束、七轴零空间姿态/避限位仍未实现 |
| 5 | Panda 位控补偿与外部目标交互 | 原始位置执行器仍有重力稳态偏差。可增加补偿选项、实时关节/位姿目标输入及记录，不把仿真参数等同于真机性能 |
| 6 | 跨平台 wheel 与 CI | 本地验证为 Linux/Python 3.12。仍需 manylinux 打包、Python 3.10+ 测试矩阵及 Ubuntu 22.04 安装验证 |
| 7 | 真机与 MoveIt 数值对照 | 尚未验证真实机器人、通信抖动/断流、设备制动或逐步 MoveIt 数值等价；需要独立实测 |

每一项都应完成接口、行为测试和文档后再标记完成。当前版本不会自动提供避障路径、硬实时周期或真实设备的停止执行。
